Un widget de clima integrado en una web de viajes que permite buscar el clima de cualquier ciudad del mundo usando datos reales de OpenWeatherMap.

¿Qué puedes hacer en el widget?
 Buscar ciudades
 Ver el clima actual
 Ver el pronóstico de 5 días

Esta hecho en 
Angular 17+

Con una API externa de OpenWeatherMap 

Angular CLI — para crear y correr el proyecto
Node.js + npm — paquetes
VS Code — editor de código
